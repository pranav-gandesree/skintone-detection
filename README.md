# Skin Tone Detection and Body Shape Analysis

## Overview

This project focuses on image-based skin tone detection and body shape analysis using computer vision techniques. It is organized into two modules: `skincolor` for skin tone analysis and `bodyshape` for body shape analysis.

The project explores how image processing and computer vision can be used to analyze visual characteristics from images.

## Features

- **Skin Tone Detection:** A module dedicated to skin color and skin tone analysis.
- **Body Shape Analysis:** A separate module for body shape-related analysis.
- **Image-Based Processing:** Designed around analyzing visual information from images.
- **Modular Structure:** Keeps skin color and body shape functionality organized separately.

## Limitations

- Results may vary depending on lighting conditions, image quality, camera settings, and preprocessing.
- Image-based estimates may not accurately represent a person's actual skin tone or body shape.
- The output should be treated as an estimate rather than a definitive assessment.
